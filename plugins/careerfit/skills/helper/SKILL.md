# 길잡이

## 1. 상태 읽기
- `CAREER.md` 유무. 없으면 바로 "setup으로 커리어 정리부터"
- 이력 저장소 노트 수, `[확인 필요]`가 남은 노트 수 (`임팩트: 핵심` 노트 우선)
- 기본본 3종 유무와, 가장 최근 프로젝트 노트 `modified`보다 오래됐는지
- `<applications>/*/진행 상황.md`에 처리되지 않은 `기본본 갱신 필요` 항목 수
- `python3 ${CLAUDE_PLUGIN_ROOT}/scripts/status.py scan <applications>`: 상태별 건수, `준비 중`이면서 `진행 상황.md`에 "제출 가능"이 없는 건
- `insights.md` 마지막 갱신일

## 2. 제안
해당하는 것 1~3개만:
- 설정 없음, 또는 설정은 있는데 기본본 없음 → setup
- 기본본이 저장소보다 오래됨, 또는 `기본본 갱신 필요` 항목이 쌓임 → update
- 새 프로젝트가 끝났다고 함, 수치·사실을 고치자고 함 → update
- `[확인 필요]`가 많은 핵심 프로젝트 → update (근거 확인 인터뷰)
- 공고를 받았다고 함 → apply
- 준비 중인데 검수 전 → apply 이어서 (검수)
- 결과를 들었다고 함, 또는 서류 전형·면접 대기 건 → track
- 결과가 3건 이상 쌓였는데 인사이트가 오래됨 → track 회고

## 3. 연결
- 사용자가 고르면 해당 스킬로 넘긴다. 자연어 요청이 한 스킬에 분명히 해당하면 제안 없이 바로 그 스킬로
