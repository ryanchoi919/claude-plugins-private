# 진행 내역·회고

## 1. 상태 갱신
- 상태는 이 8개만: `준비 중` / `서류 제출` / `서류 전형` / `서류 탈락` / `면접` / `최종 합격` / `불합격` / `지원 취소`. 사용자 표현을 이 중 하나로 옮기고 (예: "준비중" → 준비 중, "서류 진행 중" → 서류 전형, "취소" → 지원 취소), 애매하면 묻는다
- `python3 ${CLAUDE_PLUGIN_ROOT}/scripts/status.py scan <applications>`로 대상 폴더를 확인한다. "나머지 전부" 같은 표현은 대상 목록을 보여주고 확인받는다. 이미 다른 최종 결과(예: 지원 취소)인 건은 바꾸지 않고 알린다
- 각 건: `python3 ${CLAUDE_PLUGIN_ROOT}/scripts/status.py set <공고.md> <상태> "$(date "+%Y-%m-%dT%H:%M:%S%:z")"`. `상태` 속성이 없는 옛 공고에는 스크립트가 `상태`만 추가한다

## 2. 결과 기록
- `진행 상황.md`가 있으면 `# 결과 (YYYY-MM-DD)` 섹션에 상태와 받은 피드백·면접 질문·사용자 판단을 한두 줄로
- 잘못 기록한 것을 되돌릴 때는 결과 섹션도 함께 지우거나 고친다

## 3. 회고
- 결과(서류 전형 이상 또는 탈락)가 새로 생기면 `insights.md` 표에 행을 추가한다: 지원 건, 공고 유형, 결과, 전면 프로젝트, 강조점, 갭, 메모 (브리프의 포지션 해석·이야기 설계·적합도 매트릭스에서 가져온다). 표 형식은 `${CLAUDE_PLUGIN_ROOT}/references/schemas.md`
- 같은 공고 유형이 3건 이상 쌓이면 `## 패턴 요약`을 갱신한다. 표본이 적으면 "가설"로 표시하고 단정하지 않는다
- `CAREER.md`의 `## 저장 후 처리`를 수행한다
