# 한국어 AI 티 점검표

출처: [im-not-ai (Humanize KR)](https://github.com/epoko77-ai/im-not-ai) v2.4.7 분류 체계(MIT, © epoko77-ai)에서 블로그·커뮤니티 산문에 쓰는 패턴만 골라 줄였다. 괄호 안은 원본 패턴 ID. 전체 85개 패턴과 근거는 원본 `skills/humanize-korean/references/ai-tell-taxonomy.md`에 있다.

프로젝트 규칙(`CONSTITUTION.md`의 Voice & Tone, `VOICE.md`의 공통 체크리스트)이 이 표와 다르면 프로젝트 규칙을 따른다.

## 고치기 전에 지킬 것
- **고치지 않는 것**: 고유명사·제품명, 수치·날짜, 발화자가 있는 직접 인용, 표준 기술 용어(API·prompt·token 등은 직역하지 않는다), 코드
- **서법 유지**: "~해야 한다"를 "~한다"로, "~일 수 있다"를 단정으로 바꾸지 않는다. 주장의 강도는 그대로 둔다
- **빼기만 한다**: 고치면서 원문에 없던 비유·상투구·결산 문장("결국 ~하는 이유다")을 새로 만들지 않는다
- **과하게 고치지 않는다**: 걸린 곳만 고친다. 글 전체를 다시 쓰면 목소리가 사라진다

## 번역투 (A)
- "~에 있어(서)" → "~에서"(A-3)
- "경쟁력을 가지고 있다", have/make/take+명사 직역 → "경쟁력이 강하다"(A-7)
- "판단되어진다", "~지게 된다" 이중 피동 → "판단된다", 능동(A-8)
- "AI에 의해 생성된" → "AI가 만든"(A-9)
- "~에서의/~으로의/~에로의" 이중 조사 → 절로 풀어쓴다. "앞으로의"·단순 "~의"는 그대로(A-19)
- 추상 주어 + 만능 동사("이 기능은 효율성을 제공한다") → 사람·구체 주어로(A-15)
- 명사 앞 3어절 넘는 긴 관형절 → 문장을 나눈다(A-18)
- "~에 대해"·"~를 통해"·"~을 위해" → 한 문단에 세 번 넘게 몰릴 때만 줄인다. 사람도 자주 쓴다(A-1·A-11)
- "단순한 X를 넘어 Y" → "X만이 아니라 Y"로 풀거나 뺀다(A-21)

## 영어 병기 (B)
- 한글(영어) 괄호 병기는 첫 등장에만(B-1)
- seamless·robust·leverage 같은 광고성 영어는 한국어로 푼다(B-2)

## 구조 (C)
- "A가 아니라 B", "A인가, B인가", "~것이 아니라" 대구는 글 전체에서 한 번만. 나머지는 바로 단언한다(C-8, 판별력이 가장 높은 신호)
- 연결어미 뒤 쉼표("~했고, ", "~하며, ", "~하지만, ", "~해서, ")는 뺀다. 고치면서 새 쉼표를 만들면 실패다(C-11)
- 짧은 불릿이 세 덩어리 넘게 이어지면 문단으로 합친다. 순서가 있는 단계는 그대로(C-2)
- "1) 2) 3)" 나열, 문단 머리의 "먼저 / 반면 / 결국" 3단 공식 → 본문에 녹인다(C-7·C-9)
- 헤딩 "X: Y" 콜론 부제가 반복되면 명사구 하나로(C-10)

## AI 관용구 (D)
- "결론적으로 / 요약하면 / 정리하자면" 결산어는 글 전체에서 1~2번까지(D-1)
- "시사하는 바가 크다 / 주목할 만하다 / 매우 중요하다" → 지우거나 구체 결론으로(D-2)
- "크게 세 가지로 나눌 수 있다 / 다음과 같다" 열거 도입 → 지우고 바로 본론(D-3)
- "기술이 묻는다", "시대가 부른다" 의인화 추상 주어 → 사람·기관 주어로(D-5)
- "~할 때입니다 / ~시점입니다" 결말 공식 → 구체 동사로, 글당 1회 이하(D-6)
- "X에서 Y로", "X를 넘어 Y로" 변환 공식 반복 → 직접 단언으로(D-7)
- "중요한 것은 ~이다 / 핵심은 ~다 / 문제는 ~라는 점이다" 분열문 → "~가 중요하다"처럼 바로 잇는다(D-8)
- "~로 이어진다", 결산용 "결국" 반복 → 인과를 구체로, "결국"은 1회(D-9)
- 문장 끝 "~하는 이유다" 도치 → "그래서 ~다"(D-10)
- 감각 술어 평가("진단은 서늘하다"), 사전 은유(잠식·청사진·적신호·신호탄·뿌리내리다) → 명제로 푼다(D-14)

## 리듬 (E)
- 문단의 문장 길이가 다 비슷하고 100자 넘는 문장이 없으면, 이웃 두 문장을 이어 긴 문장 하나와 짧은 문장 한두 개를 섞는다. 내용은 더하지 않는다(E-1)
- 같은 종결어미가 네 문장 넘게 이어지면 바꾼다. "~하고 있다"는 단순 시제로("읽고 있다" → "읽는다")(E-2)
- 존댓말 등급(해요/합니다/한다)을 한 글 안에서 섞지 않는다(E-7)

## 수식·완곡·접속·형식명사 (F·G·H·I)
- "~적 N" 추상 체인("전략적 함의")이 세 번 넘으면 풀어쓴다(F-5)
- 같은 추측 종결("~로 보인다")의 반복 → 종결 형태만 바꾸고 유보 강도는 유지. 단정으로 바꾸지 않는다(G-1)
- "~할 가능성이 있을 수 있다" 이중 완곡 → 하나만(G-2)
- 문두 "또한 / 따라서 / 즉 / 나아가"가 연달아 나오면 줄인다. "즉"은 글당 2회 이하(H-4)
- "주목할 점은 ~라는 점이다", "~다는 것이다" 결말 → "~다"로 바로 끝낸다(I-2·I-3)
- 당위("~해야 한다")로 끝나는 문단이 둘 넘으면, 첫 문단만 두고 나머지는 당위 문장을 문단 앞·중간으로 옮긴다(I-4)

## 시각 장식 (J)
- 문장마다 **볼드** → 본문 볼드는 거의 뺀다(J-1)
- 강조용 "따옴표"가 다섯 번 넘으면 진짜 인용만 남긴다(J-2)
- 대시(—) 부가 설명 → 쉼표·괄호·별도 문장으로(J-3)
- 이모지를 리스트 머리·헤딩에 쓰지 않는다(C-5)
